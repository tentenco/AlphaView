# Alpha 研究流程：本輪互動決策

使用者是會比較四個技術策略、已有持倉與大型候選池的個人研究者。主要工作是快速找出值得進一步研究的候選，同時看見持倉提醒；不是先操作一整套回測參數。

現況：Alpha 卡片適合看少量共識候選，但切換全部約千檔時，逐張翻頁的負擔較高。實驗功能若直接展開在首頁，會把今日候選推到太遠的位置。

目標：從首頁在一個候選區完成快速掃讀、篩選、比較與研究；深入分析有獨立目的地。成功訊號是能在不用修改持倉的情況下找到新候選、查看其分數與風險，並帶入比較或實驗。

| 決策 | 對象、範圍、後果與可逆性 | 規則與依據 |
| --- | --- | --- |
| 卡片／表格／分布圖候選檢視 | 只改呈現密度；保留篩選與排序，不改分數或持倉；立即可切回 | `rule/control-matches-cardinality`、`rule/preserve-mental-model`；使用者希望快速看到選股 |
| Alpha 實驗室獨立目的地 | 回放與配置是較長的研究工作，從首頁可到達並返回；不與今日排名混在同一畫面 | `rule/inline-before-modal`、`rule/smallest-intervention`；進階功能不增加預設路徑的負擔 |
| 實驗權重獨立，明確套用才更新首頁 | 調整只影響實驗；按「套用到 Alpha Picks」才保存首頁研究偏好，保留提醒門檻 | `rule/name-object-scope-consequence`、`rule/preserve-user-input` |
| 卡片收藏與比較互不改動持倉 | 星號保存研究代碼；比較最多五檔；零股觀察有獨立操作 | `rule/name-object-scope-consequence` |
| 風險與資料缺漏分開呈現 | 高共識不會抵銷風險；資料缺漏不當作策略退出或跌價訊號 | `rule/cover-reachable-states`；本機資料有有效、異常、缺漏三種現況 |
| 手機保留完整操作 | 表格可水平捲動；卡片和表單改單列／雙列；可用鍵盤完成主要流程 | `rule/keyboard-complete-flow`、`rule/accessible-name-required` |

所有本機使用者都能操作，沒有本輪新增的登入或權限路徑。載入中、空清單、篩選零結果、部分資料、版本過期、設定無效、儲存失敗與下載失敗是可到達狀態；它們需要留在原流程並提供恢復方法。沒有新增券商委託、伺服器外部推播或帳戶管理。瀏覽器桌面通知由使用者自行啟用，且需要頁面保持開啟。

實作沿用專案既有字型、顏色與淺／深色 tokens。此文件是產品決策紀錄，不是聲稱已完成所有 UI 驗收。

新增的候選排序與指標篩選只影響清單，完整股票池統計不變；手機將篩選拆成可閱讀的列，而不是壓縮下拉選單。每日 HTML 帶出來源快照與收盤提醒設定。研究快照中的提醒明確標示為保存時的條件，不能把它當成當期風險判斷。複查行事曆是明確下載的本機 ICS，不會自動寫入行事曆或啟用通知。
