# 標的調整價格比較

`GET /api/comparison?symbols=AAPL,MSFT&window=60` 僅讀取本機已儲存日線，不下載行情，也不修改持倉或策略。可選目前個人清單與美股候選池中的 2–5 檔不同標的；期間為 60、120 或 252 個 XNYS 交易日日報酬區間。

每個期間需要 N+1 筆價格：截至最新已收盤且經過 15 分鐘的交易日，向前取 N 個交易日間隔。所有可用標的使用完全相同的起日、迄日與日期序列，以起日調整收盤價為 0%，逐日計算 `(當日調整收盤價 / 起日調整收盤價 - 1) × 100`。沒有向前填值、跨缺日連接或替近期上市標的縮短區間。

來源紀錄必須是成功更新、美元、可確認實際名稱和交易所的 Yahoo Finance / yfinance 快取，筆數須與本機日線一致，末日須等於最新已完成交易日。SPCX 另保留既有身份與上市日期檢查。所選區間若有缺日、非交易日或無效 OHLC／調整價格／成交量，整條序列標示不可用，並提供原因、已觀測與有效筆數。數值超出有限浮點計算範圍也不輸出曲線。

`status=ready` 表示至少兩檔可用；`complete=true` 表示所有請求標的均可用。其他標的即使不可用，仍保留在結果中。各條可用曲線共有同一組 `dates`；少於兩檔時，介面應顯示涵蓋不足，不建立比較圖。

此功能是個別標的的調整價格比較，不是歷史持股績效、投資組合報酬、含費用策略回測或經獨立驗證的含息總報酬。調整價格沿用既有來源資料，不重建股息、拆股或其他公司行動。

所有成員、來源紀錄及日線在同一 SQLite 讀取快照取得。回應附 `input_revision` 與 `comparison_engine_version=alphaview-comparison-v1`，用於識別資料與計算方法；方法有實質變更時需遞增版本。API 不提供歷史任意截止日，也不把舊價格移至最新交易日。每次最多五檔、253 個必要價格，SQL 與處理設有十秒預算；資料庫忙碌或超時回傳 503。
