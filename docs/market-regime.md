# 市場風險溫度計：多因子崩盤風險分數

「市場風險溫度計」把開源專案 [US_Stock_Crash_Monitor](https://github.com/middletoo/US_Stock_Crash_Monitor)（middletoo，Gemini 3 協助撰寫、MIT 授權）的多因子風險加權模型，整合到 AlphaView 的市場概況頁。AlphaView 原本由下而上找個股（四策略選股與 Alpha 排序）；這個模組補上由上而下的市場背景：估值是否偏貴、利率曲線處於哪個階段、指數離長期均線多遠、情緒是否過熱。分數是規則共識，不是崩盤預測，也不是操作指示。

方法版本：`alphaview-regime-v1`。位置：`http://127.0.0.1:8876/#market` 頁面頂端。

## 上游方法論與我們的取捨

| 上游作法 | AlphaView 的處理 | 原因 |
| --- | --- | --- |
| 五因子（巴菲特指標、Shiller CAPE、10Y−2Y 利差、200 日均線乖離、恐懼與貪婪）各自以固定門檻映射為 0–100 風險，再線性加權 | **完整沿用**門檻與預設權重（15／25／25／20／15） | 這是該專案的核心思維；門檻參考 2000、2008、2021 年崩盤前的水準 |
| 權重總和不等於 100% 時只顯示警告 | 權重以合計正規化（與 Alpha 分數相同口徑）；合計為 0 拒絕計算 | 使用者不必湊 100，仍有明確定義 |
| GDP、CAPE、2 年期殖利率、恐懼與貪婪由使用者手動填入，側欄附資料來源連結 | **沿用手動輸入**，另加每筆讀數的**資料日期**與過期提示（巴菲特 120 天、CAPE 45 天、利差 10 天、情緒 7 天） | 這些序列沒有本機行情來源；日期讓過期讀數被看見而不是被隱藏 |
| 10 年期殖利率由 `^TNX` 自動抓取 | 兩段殖利率都手動輸入（FRED DGS10／DGS2） | AlphaView 只從 yfinance 取股票日線；不新增指數型代碼與第二來源，避免未經驗證的資料混入 |
| 指數乖離用 VOO／QQQ 的即時 `history()` | 從**本機已儲存的基準 ETF 日線**（VOO／SPY／QQQ）計算股息調整收盤價與 200 日均線；沒有日線就標示不可用 | 沿用「不下載、不填補」與交易日新鮮度檢查；把 VOO 以零股加入觀察名單即可取得資料 |
| Yahoo 連線失敗時切換到「模擬演示模式」隨機價格 | **不採用** | 違反「不捏造資料」原則 |
| 依分數輸出「大幅降低倉位、買 Put 對沖」等建議文字 | **不採用**；區間只描述歷史參考位置 | 研究訊號不是交易指示 |
| 2000／2007／2022 三個歷史情境用目前權重重算，與現在比較 | 沿用，讀數標示為**上游整理的近似值** | 有助校準權重；但這些不是逐日驗證的資料集 |
| 缺任何輸入時用預設值算出分數 | 任一啟用因子缺資料，綜合分數即**不可用**並列出缺項；不把權重挪給其他因子 | 與 Alpha 分數一致；避免部分資料產生偏低的假分數 |

## 因子與門檻

| 因子 | 讀數 | 風險對應 |
| --- | --- | --- |
| 巴菲特指標 | 美股總市值 ÷ GDP（%） | >200 → 100；>180 → 90；>150 → 75；>120 → 50；其餘 25 |
| Shiller CAPE | 經通膨調整的十年盈餘本益比 | >40 → 100；>35 → 90；>30 → 70；>25 → 50；其餘 20 |
| 10Y−2Y 利差 | 10 年期減 2 年期公債殖利率（百分點） | <−0.5 深度倒掛 → 80；<0 輕度倒掛 → 60；0 至 0.5 解掛／平坦 → 70；其餘正常 → 30 |
| 200 日均線乖離 | （調整收盤 − MA200）÷ MA200 × 100 | >25 → 100；>20 → 85；>15 → 65；>5 → 40；<−10 → 10；其餘 20 |
| 恐懼與貪婪 | CNN 指數 0–100 | >80 → 100；>60 → 70；<20 → 0；其餘 40 |

上游特別強調利差「倒掛後回正」是歷史上最危險的時刻（2007 年 10 月），所以 0 至 0.5 的解掛區風險高於輕度倒掛；這個非單調設計被保留。

`綜合分數 = Σ（因子風險 × 權重）÷ 權重合計`。區間：0–40 低風險、40–60 中性觀察、60–80 風險累積、80–100 極高風險。

## 歷史參考情境（預設權重）

| 情境 | 巴菲特 | CAPE | 10Y／2Y | 乖離 | 情緒 | 分數 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 2000-03 網路泡沫頂部 | 145% | 44.2 | 6.2／6.6 | 15% | 90 | 70.5 |
| 2007-10 金融海嘯前 | 110% | 27.5 | 4.6／4.2 | 8% | 75 | 52.25 |
| 2022-01 升息熊市頂部 | 195% | 38.3 | 1.6／0.8 | 12% | 75 | 62.0 |

讀數取自上游 README 與程式的參考表，是近似值。值得注意的是 2007 年只有 52.25：這個模型以估值為主，而 2007 年不是估值泡沫，主要訊號來自利差解掛。這是模型的已知限制，不是資料錯誤。

## 資料輸入

手動讀數存在**目前瀏覽器**的 `localStorage`（`alphaview-market-regime-v1`），不在工作區 ZIP 備份、不在 Alpha 研究資料搬家 JSON 中；清除瀏覽器資料即消失。介面提供的來源連結：

- 巴菲特指標：Longtermtrends（總市值／GDP）、FRED `GDP`
- Shiller CAPE：multpl.com、Robert Shiller 線上資料
- 殖利率：FRED `DGS10`、`DGS2`
- 恐懼與貪婪：CNN Markets

技術因子基準預設 VOO，可切換 SPY 或 QQQ。基準必須在本機有通過品質檢查、最新日期等於最新已完成交易日、至少 200 筆的日線；不足時該因子標示原因（`no_history`、`stale_history`、`data_error`、`insufficient_history`），綜合分數保持不可用。取得方式：在「我的持股」把 VOO 以零股加入觀察，再更新行情。注意 09-05 的診斷顯示 SPY 最新日線曾出現非有限值（見[來源評估](data-provider-evaluation.md)）；未通過檢查時以 VOO 或 QQQ 替代，或等待資料源修正。

## API

`POST /api/market/regime`：唯讀，使用一致的 SQLite 讀取快照，不寫入、不下載行情。

```json
{
  "weights": {"buffett": 15, "shiller": 25, "yield_curve": 25, "technical": 20, "sentiment": 15},
  "inputs": {
    "buffett_ratio": {"value": 190, "as_of": "2026-06-30"},
    "shiller_pe": {"value": 38.1, "as_of": "2026-08-31"},
    "yield_10y": {"value": 4.1, "as_of": "2026-09-03"},
    "yield_2y": {"value": 3.6, "as_of": "2026-09-03"},
    "fear_greed": {"value": 55, "as_of": "2026-09-04"}
  },
  "benchmark": "VOO"
}
```

範圍：巴菲特 0–1000、CAPE 0–200、殖利率 −5–30、情緒 0–100；權重 0–100 且合計大於 0；日期不可為未來；`benchmark` 限 VOO／SPY／QQQ；未知欄位拒絕。回應包含 `engine_version`、`as_of`、`input_revision`、逐因子的 `value／risk／weight_pct／as_of／age_days／stale／reason`、`score／zone／complete／missing／stale_inputs`、基準日線狀態、三個情境的重算結果與 `method` 說明。完整欄位見本機 `/docs`。

## 驗收

```sh
uv run --extra web --extra dev pytest -q tests/test_market_regime.py
npm test --prefix web -- src/MarketRegime.test.tsx src/market-regime.test.ts
```

後端測試涵蓋每個門檻邊界、三個情境的分數（70.5／52.25／62.0）、缺因子不重分配權重、權重正規化與零合計、過期讀數只標示不剔除、利差需兩段輸入、基準日線缺少／過期／異常／不足 200 筆、API 範圍驗證與不寫入資料庫。前端測試涵蓋掛載時以已存設定送出請求、不完整狀態不顯示假分數、完整分數與區間、輸入驗證與 localStorage 往返、錯誤重試。

## 已知限制與後續

- 線性加權無法描述非線性連鎖反應；GDP 與 CAPE 有季度／月度滯後；讀數與權重包含使用者判斷。這些是上游 README 自述的限制，在此同樣成立。
- 尚未把區間接到 Alpha Picks 首頁或持倉提醒；下一步可在首頁顯示目前區間，並把「極高風險」列為獨立資料提醒（不抵銷個股訊號）。
- 尚未納入研究資料搬家（`alpha-transfer.ts`）；納入時要同步擴充匯入預覽與 allowlist。
- 若日後接入 FRED 或其他自動來源，依 [來源評估](data-provider-evaluation.md) 的授權與驗收條件另開範圍，並為讀數加上來源與抓取時間。
- 門檻或公式若有實質變更，遞增 `alphaview-regime-v1` 並在此記錄。
