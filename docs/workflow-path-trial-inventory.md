# 已保存路徑試驗清單

方法版本：`alphaview-workflow-path-trial-inventory-v1`。這是一份帳戶層級的唯讀盤點，用來在檢視 CSCV 前了解實際保存了哪些設定、哪些重複保存，以及哪些歷史來源無法放在同一比較基礎。

範圍固定為 `saved_receipts_only`。未保存、已捨棄或從未留下收據的探索試驗數，以及完整搜尋分母，皆為 `null`／unknown。已保存零筆不是做過零次試驗。完整試驗登錄仍未完成，留待後續 Harness；此功能不補寫歷史、不推測未記錄的試驗。

## API、完整集合與限制

`GET /api/paper/accounts/{account_id}/workflow-path-trial-inventory`。

32 位小寫十六進位帳戶 ID 必須存在。端點使用 `@store.snapshot_read`；完整集合、帳戶版本、輸入版本及來源當期狀態在同一 query-only 快照取得。`as_of` 使用 `sessions.latest_completed_session()`，讀取期間交易日變更回傳 409。無新增 schema、寫入或資料遷移。

集合包含此帳戶跨工作流、所有分頁的 `path_validation`、`path_costs` 及未知 kind 紀錄。依帳戶欄位精確儲存位元組界定範圍，BLOB 同值仍納入，卻不當作可驗證文字收據。成本收據單獨計數，不計成 path trial configuration。異帳戶資料不納入。

每帳戶最多 50 筆、全域最多 250 筆；超限拒絕整份清單。每列 payload 讀取上限沿用 2 MiB，保存請求 16 KiB。超限原件不解碼，但仍保留該列的身分、原始位元組長度與不可用原因。每列原始識別欄位總計最多 16 KiB，超限回傳 413，不截短識別。完整回應最多 3 MiB，超限回傳 413，不省略紀錄或只提供部分下載。

下載是完整盤點回應原文，包含所有身分、原始內容指紋、設定、比較基礎摘要、計數與來源當期狀態。它不重複包含完整原始收據 payload；原件使用既有個別收據或封存下載。損壞識別欄位另附 SQLite 型別、編碼、長度、雜湊和原值，不替換成看似有效的 ID。

## 可驗證與可比較分開

先沿用收據封存的嚴格驗證：原始內容指紋、規範化請求、綁定、完整封裝與受理解的證據形狀。損壞、未知型別或超限內容保留為不可用列。

完整性可核對的 path 收據再用既有 `workflow_path_receipt_comparison._basis(payload, payload)` 核對完整比較條件，同時核對支援的方法版本與方法文字。有效的 `unavailable` 收據仍保留原始設定，但不會被放入完整可比較分組。

分組只按以下 versioned canonical facts 的精確指紋相等：

- 收據／研究／路徑／工作流／掃描／配置方法版本與定價方法說明。
- 原始歷史指紋、原順序的 candidate 與 RPS universes。
- 完整精確視窗、估值日期數量、起訖日期與完整日期指紋。
- 完整覆蓋與有限必要指標是否成立。
- 初始現金與基準費用／滑價。

必要指標只用於既有完整性條件，不對外提供報酬、NAV、排名、勝出者或績效數值。分組不靠兩兩相似、傳遞性推測、日期交集、重定基準或補值。Canonical basis 同時包含 inventory 與 comparison 方法版本；任何指紋碰撞且內容不同都會拒絕。

覆蓋條件與 CSCV 共用比較 helper 一致：每一原件都必須完整，不額外發明「不同 rebalance 設定一定要有相同決策數」的條件。原始決策／估值覆蓋計數另保留在每列。

## 設定與重複保存

設定定義與指紋直接沿用 CSCV `_configuration` 與收據 canonical hash，包含完整 baseline settings、saved workflow request、workflow kind、candidate symbols、RPS universe。設定維持保存時的規範化形式。必要設定欄位缺少、不是可理解的 deterministic_rules 工作流，或無法核對時，保留該列為設定不可用，不補上設定，也不使整份清單失敗。

每個精確比較基礎組內列出設定指紋、完整設定、multiplicity 與所有原始收據 ID。重複設定不刪除、不合併成一筆收據，也不偷偷縮小試驗母體。相同設定若屬不同資料基礎，分別列在不同組，不跨組合成同一母體。「各組設定數合計」明確是組內 distinct counts 的合計，不宣稱跨組全域唯一設定數。

有效歷史收據即使帳戶、來源輸入、工作流或目前交易日改變，仍可留在原比較分組。每列 currentness 與原因另外呈現；它是本次讀取的觀察，不是持續即時保證，也不更改歷史設定與指紋。

## 介面與檢核

`WorkflowPathTrialInventory` props：`accountId`、`accountVersion`、`enabled?`（預設 true）、`t`。掛載不 fetch；明確載入才讀取。手動下載使用接受的完整 response.text，保留原始數字文字、Unicode、未知未來欄位和 null，不以畫面篩選結果重建下載。

分類、ID／工作流／指紋搜尋和 25 筆分頁只影響紀錄清單。完整帳戶涵蓋、不可用數、重複次數、比較分組、未知搜尋分母與完整下載保持可見。空搜尋結果不會遮住不可用紀錄的總數。原生 details 可展開每組全部收據 ID、規範化設定、基礎與原始識別儲存型別。

同步鎖阻擋連點。帳戶、版本、enabled 或卸載取消舊請求；晚回應不能恢復舊資料。重新載入先撤下舊下載，失敗不保留看似新鮮的結果。來源與分組回應驗證失敗時不提供下載。Blob URL 延後清理；長識別與設定在 390px 排版換行。沒有自動填入 CSCV、執行計算、儲存篩選或修改路由。

## 這不是什麼

這不是事前登錄、完整試驗登錄、未保存探索歷史的重建、完整搜尋 PBO、獨立樣本或樣本外證明。完整可比較基礎也不代表 CSCV 通過；清單沒有推薦設定、獲利承諾、績效排名或執行資格。所有現有研究、保存和 CSCV 計算語意不變。
