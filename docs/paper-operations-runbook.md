# Paper 無人值守運作手冊（Trading Agent 最後一哩路）

這份手冊把 2026-10-01 Harness 交付的各個閘門串成一條可以每天跑的流程。範圍只到 **paper**：本機模擬帳本與 Alpaca Paper 唯讀＋明確啟用的 Paper 委託。沒有實盤券商目標、沒有推播、沒有公開部署；任何「上線讓大家使用」的多使用者條件仍列在 `docs/execution.md` 的路線圖，未實作。

## 一次性設定

1. **資料**：資料管理頁更新行情，確認股池與 `SPY` 都有本機日線（進階指標與決策結果帳本的基準都用它）。
2. **虛擬帳戶**：Agent 投資組合建立帳戶、設定限制（單一標的上限、換手上限、最低現金）。
3. **風險層**（風險控管分頁）：
   - 風險斷路器：日損、最大回撤、當日成交筆數三個門檻都要設；視需要勾選「純減倉例外」。
   - 部位停損：啟用停損／追蹤停損與冷卻交易日。
   - 市場風險覆蓋：先在市場風險溫度計頁填好手動總經讀數，再在覆蓋面板載入設定並選 block 或 scale。
4. **決策層**：規則工作流（角色、配置方法）；可選 Jev 門檻（需 TypeSafe 連線，`docs/jev-decision-layer.md`）。
5. **執行層**（交易代理分頁）：目標選本機模擬帳本或 Alpaca Paper；後者要在 Alpaca 頁設定金鑰、輸入確認字串啟用委託並設定每筆金額／筆數／成交量參與率上限。
6. **授權**：建立 mandate（本機自動化任務），選擇執行目標與 Jev 門檻；自動模式會真的建立並送出提案。
7. **就緒閘**：交易代理分頁頂部的就緒檢查全部通過（`paper_ready`）後才開啟無人值守；任何 `not_ready` 項目都要先處理，不要用例外繞過。

## 每個交易日

| 時點（美東） | 動作 | 由誰 |
| --- | --- | --- |
| 收盤後 15 分鐘 | 行情更新與每日選股發布 | 本地收盤排程 |
| 之後 | 自動化任務：Jev 門檻 → 市場風險覆蓋 → 斷路器 → 提案 → 執行目標 | mandate（自動）或使用者（手動接受） |
| 送出後 | 執行層每 120 秒核對 Alpaca Paper 委託；未知結果只核對不重送 | 背景核對 |
| 任何時候 | 帳簿核對（Alpaca 頁）：帳簿成交 vs 券商持倉 | 使用者按下 |
| 隔日 | 每日 Agent 報告（NAV、成交、成本、Jev、嘗試）；決策結果帳本在 5／10／20 日後結算 | 使用者檢視 |

## 異常處理

- **斷路器觸發**：帳戶自動暫停；只有勾選純減倉例外的帳戶可接受減倉提案（例如停損出場）。恢復需明確操作並留下 resume 紀錄。
- **就緒閘變成 blocked／not_ready**：停止自動模式，處理列出的項目；不要調整門檻讓它變綠。
- **帳簿核對出現 drift／unexplained**：先查 Alpaca 委託頁與執行層的委託紀錄；手動在 Alpaca 介面交易會顯示為 unexplained，本工具不會自動修正。
- **Jev／行情不可用**：門檻與覆蓋都是 fail-closed（block）或明確標示略過（scale）；不會用舊值或預設值替代。
- **殺手開關**：帳戶控制的 kill switch 立刻阻擋所有加倉；純減倉例外仍可出場。

## 什麼時候不要跑

- 行情更新失敗、股池日線過期、`SPY` 缺價：決策結果、進階指標與覆蓋都會標示不可用，不要在不可用狀態下接受提案。
- 驗證閘對目前策略設定是 `fail`，或分段一致性、bootstrap 區間、機率化 Sharpe 任一不可用：先回研究台調整，不要直接上自動化。
- 決策結果帳本顯示某家族命中率長期偏低且樣本足夠：停用該來源的自動化，改手動審閱。

## 這不是什麼

- 不是實盤操作指引；所有成交都是 paper。
- 不保證獲利；所有統計都是小樣本、單一資料來源、無股息與稅務的近似。
- 不是多使用者產品：單機、單使用者、loopback。

## 風險設定草稿與跨視窗更新

風險控管分頁的斷路器、部位停損與市場覆蓋各自保留未保存草稿。背景取得不同帳戶或設定版本時，畫面提示版本已改變並保留輸入；必須明確選「載入目前設定」才會捨棄該草稿並採用最新設定。409 衝突或重新載入失敗不會把草稿清掉。保存途中繼續編輯的新內容也不會被較早請求的回應覆蓋。這不是自動合併，多個視窗的修改仍由使用者重新檢閱。


## 10/03 本機檢閱工具

- 所有帳戶待辦可把特定版本的事項標為已檢閱，或切回未檢閱。這不表示風險解除；內容變更時會重新提醒，來源不可用仍保留。
- Agent 工作流的配置方法比較可下載 CSV，包含顯示結果的來源與缺值原因。草稿修改不會重算已顯示結果。
- 回測研究台的診斷可按需比較歷史前綴；它只找抽樣範圍內的具體反例，不證明策略無未來資料偏差。紙上橋接沿用診斷期間與風險假設，最新訊號日仍獨立檢查。
- 本機模型的已保存分析可離線重驗證據，不需要模型服務運作。歷史一致不代表來源仍可用；原始文字預設隱藏，需明確揭露。
- 配置預覽下方的成本敏感度固定模擬股數，改變費用／滑價假設；成交量缺值保持不可用。它不改執行政策，不會保存提案或下單。
- Alpaca Paper 帳簿核對按鈕會明確讀取券商並保存本機回條；就緒檢查只讀回條，15 分鐘或來源變更失效。開發與本文件驗證使用假券商，沒有向真實帳戶送單。
- 自動化結果保護採工作區來源家族統計。足量低命中率或證據無法評估時，當次改為人工審閱；任務設定不變，樣本不足不單獨降級。這不是策略績效認證。

### 工作流研究與可追溯性

Agent 工作流可先選已保存的歷程，再以另一份歷程為基準比較。差異分成候選與權重、設定、來源版本；方法或行情同時改變時不能把結果歸因於某個參數。受阻或未記錄的權重顯示不可用，不以零代替。這個比較不重算策略，也不代表哪份配置績效較好。可下載當次完整比較 JSON；改選基準或等待新回應時會停用舊下載，檔案保留缺值與當次來源標示。

目前有效工作流可按需查看單項規則驗證，下載完整 JSON 留供離線檢閱。RPS 等未支援規則仍計入覆蓋缺口，沒有整體組合「通過」結論。調整輸入或來源後，先前下載按鈕會移除，必須重新計算。

排名／等風險貢獻研究固定已保存標的、投入預算與單檔上限，使用共同日期的完整調整收盤。缺值、共變異退化或求解未收斂時整份研究不可用；上限多出的權重保留現金，不重新分配。結果不會修改主動配置方法或建立提案。

待辦可按結構化來源篩選；篩選只影響呈現，風險計數維持全域。帳戶／檢視／分頁可以用本機 hash 連結回到原處；它不包含未保存草稿或授權。

### 公司行動與清掃紀錄

風險控管的公司行動卡片並列調整價推算與 yfinance 回傳證據。先看來源覆蓋、未知儲存格及事件修訂；沒有推算事件，不代表來源證明沒有事件。「重新讀取本機證據」只讀本機。需要重抓時，明確按所持有標的的「更新兩年行情並重檢」，可重新整理回到作業狀態或要求取消。取消須等目前下載結束，已原子提交的日線可以保留；重檢成功仍不表示異常已修復，也不調整股數、成本或現金。

交易代理的單筆 Alpaca Paper 明細會保留最近清掃時間、原因與逐筆動作。原因選單只篩選這一筆送出紀錄，切換篩選不呼叫券商。歷史 cancel_requested 只表示曾要求取消；目前若已 filled，仍顯示成交。舊回條缺漏或身分不一致時保留不可用，不猜測結果，也不因顯示原因而重送委託。

歷史前綴診斷可下載完整 JSON。修改研究表單、載入其他結果或新的診斷時會清掉舊下載；要保留特定檢查，請在該次結果仍有效時下載。檔案保留抽樣限制及缺值，沒有「通過即安全」的保證。


### 保存不可變配置研究

排名／等風險貢獻研究計算完成後，可保存當次研究收據。伺服器會重建結果並核對工作流、行情、交易日、帳戶版本與標的政策；任一條件變更，拒絕新保存。相同請求回放原收據，不增加筆數。

從「讀取帳戶收據歷史」可檢閱原本的權重、缺值、覆蓋、求解證據與帳戶條件；歷史過期不會重新計算。當期標示只反映該次讀取，需重新讀取才能核對目前條件。匯出所選收據 JSON 只下載已讀取的完整回應，不觸發資料更新或送單。每帳戶50筆、全域500筆、每筆256KiB；達上限拒絕新增，不會自動刪除舊證據。

可選兩份同帳戶收據，比較原本保存的權重、現金與風險貢獻。只有方法、標的、視窗與覆蓋相容時才提供差值；過期歷史仍保留當時的數值。匯出這次比較 JSON 保留完整回應、不可用原因與來源標示；改選、重新讀取或等待下一個比較時，舊下載會移除。比較與下載不重算歷史、不建立提案。


### 檢閱逐次清掃事件

交易代理下方「已保存清掃歷程」需明確載入，每頁20筆。預設檢閱整個帳戶；開啟送出明細後，可改選「目前選取的送出紀錄」。切換範圍或選取另一份明細會清除舊結果，需重新按「讀取清掃歷程」。未選取明細時不允許限定單筆查詢。每個事件保留當次原因、清掃前狀態、動作與錯誤；可先看原本委託明細的目前狀態，再對照歷史事件。取消請求不是取消成功，後續核對仍可能顯示成交。

事件與最近一次摘要在同一筆最後交易提交；該交易失敗不會倒轉先前發出的取消請求，也不會自動重送。歷程從這個版本開始保存，不回補舊摘要；空歷程不代表之前沒有清掃。內容無法驗證時顯示不可用。檢閱有效事件後可按「下載清掃事件 JSON」，取得當次完整歷史回應；下載不重新讀取，改選或重新讀取期間不能匯出舊事件。清掃歷程不提供送單、撤單或對帳操作，沒有自動刪除或封存政策。
