# 保存路徑月報酬

`alphaview-workflow-path-monthly-v1` 把同帳戶一筆不可變 `path_validation` 原回條轉成年度十二月格與依時間排序的月份明細。它只描述保存的 252 個估值日，不重新取得價格或重跑工作流。這不是年化報酬、基準比較、排名、預測、統計通過判定、交易建議、執行來源或就緒閘；不寫入帳戶、工作流、回條或帳本，不呼叫外部資料、模型或券商。

## 原件與歷史交易日

沿用保存回條的嚴格 self-basis：完整方法版本、原始歷史資料指紋、候選與 RPS 股票池、保存期間／逐日日期、完整涵蓋、起始現金與基準成本及必要有限指標。原回條必須有 252 個正且有限的保存淨值；原訊號日的起始現金是其前一個 XNYS 交易日邊界。訊號日加逐日曲線必須逐項等於保存起訖區間的完整歷史 XNYS 日曆。

缺值、零／負淨值、非有限值、重複或亂序日期、缺交易日、不正確起始邊界、非 252 日路徑，以及不一致的保存指標，均使整份分析為 `unavailable`。`months`、`years`、`summary` 為 `null`；原件、原因及已知核對資訊仍保留。沒有日期交集、丟棄、排序、插值、補零或比例重設。

來源當前性另行觀察；來源過期但原件可驗證、保存基礎完整時，歷史月報酬仍可用。當前資料、方法版本與最新交易日不會改寫歷史月份，也不恢復目前執行資格。

## 月份邊界與部分月份

依原日期順序按 `YYYY-MM` 分組。每月的起始邊界是前一個保存觀察的淨值；首月用原訊號日的 `initial_cash`。邊界不算進當月估值日數。每月最後一個保存觀察是期末。

- 觀察月報酬：`(end_nav / boundary_nav - 1) * 100`。
- 觀察月淨值變動：`end_nav - boundary_nav`。
- 整段報酬：先乘各月 `gross_return = end_nav / boundary_nav`，再減 1、乘 100；不得直接加月報酬。
- 整段淨值變動：各月淨值變動相加，應等於期末保存淨值減原起始現金。

每一個觀察月份都用該歷史月份完整的 XNYS 交易日曆核對。只有首個、末個及其間每個交易日全部涵蓋才標記 `complete`；不能用月曆 1 日／月底日期推斷，例如 2026 年 2 月完整交易期間是 2 月 2 日至 27 日。首月晚於首個交易日、末月早於末個交易日，分別附原因並標記 `partial`；同月也可同時缺頭尾。

部分月份的**觀察報酬是已知值**，不因此抹除；但必須保留「部分月份」、實際起訖、觀察／完整交易日數、完整月份首末交易日及邊界資訊，不能當成完整月報酬。完整性只看保存歷史日曆，不看檢視當天。

每個包含觀察的年份都有十二格。原訊號現金日期本身不延伸年度顯示範圍。期間外月份標記 `outside_window`，各數值與觀察數量為 `null`，附 `outside_saved_window`；UI 顯示 `—` 與原因，不顯示 0%。觀察到的真正零報酬則顯示 `0.00%` 和「無變動」。正／負報酬同時有正負號、上升／下降文字與色彩，不只依賴顏色。

## 整段核對與有限值

核對六項：末點淨值與保存期末值、首尾報酬與保存報酬、月份串接報酬與保存報酬、月份串接與首尾報酬、月份淨值變動加總與首尾差額，以及串接後期末淨值與保存末點。每項保留計算值、參考值、差額、單位與核對結果，不修正原件。

使用 `math.isclose`：報酬絕對容差 `1e-9` **百分點**，淨值絕對容差 `1e-6` **淨值單位**，共同相對容差 `1e-10`。完整 envelope 的 `tolerances` 明列以上三值。任一核對不符使整份月份結果不可用。正淨值除法若溢位、下溢成 0，或百分比／串接／加總出現非有限值，也不回傳部分月份或假定 100% 損失。

## 唯讀 API 與 UI

`POST /api/paper/accounts/{account_id}/workflow-path-receipts/monthly`

```json
{
  "receipt_id": "<64 位小寫十六進位 ID>",
  "expected_fingerprint": "<完整回條指紋>",
  "expected_account_version": 1
}
```

嚴格請求欄位、帳戶範圍、完整指紋與當前帳戶版本，在 `@store.snapshot_read` query-only SQLite 快照內處理。外帳戶原件 404；損壞、指紋或版本衝突 409；成本回條及超過匯出上限 422。回應包含完整原件、月份明細、年度格、核對資料與方法，使用有限 canonical JSON、`Cache-Control: no-store`，整份上限 **3 MiB**，超限拒絕而不裁切。

`WorkflowPathMonthly` 接受 `accountId`、`accountVersion` 與 `t(zh, en)`。只有手動載入最多 50 筆歷史路徑回條、選取可驗證原件並檢視才請求。相同帳戶版本變更或暫時核對時保留選擇草稿並清除已接受分析；換帳戶清除全部，取消舊請求，拒收過期回應，連點不重送。年度格在 390px 寬使用三欄，長控制文字換行；月份明細只在表格內水平捲動。

下載使用已接受的原始 response text，完整包含原回條與分析，沒有第二次請求或重算。元件不將月份結果送入任何交易或 eligibility 流程。

## 已觀察月份 CSV

「下載已觀察月份 CSV」只在已接受、可用且必要欄位完整的分析出現。以 `analysis.months` 的原有時間順序逐月匯出；不讀取年度十二格裡的 `outside_window` 空格。部分月的已知報酬照原值保留，並同列 `complete`／`partial`、原因、實際起訖、觀察交易日數、完整月份首末交易日與日數、未涵蓋日數、`boundary_kind`／日期／淨值、期末淨值、gross return、總報酬百分點數值及淨值變動。百分比欄位 `total_return_pct` 的 `10` 表示 10%，不是 0.1，也未年化。

每列帶有原回條 ID、完整指紋、run ID、分析方法、`checked_as_of`、input revision 與檢視時 currentness。明確未知的 currentness 為空白；真正的零值仍是 `0`。必要來源資訊、月份、涵蓋或計算值缺漏／非有限時整份 CSV 不提供，顯示原因；不補零、不跳過問題月份、不另做計算。來源過期且原件與分析可驗證時仍可匯出，其過期原因保留。

格式為 UTF-8 BOM、CRLF、RFC 4180 引號轉義；所有文字欄位含來源資訊都防範試算表公式注入，數值保留有限原值與正負號。CSV 是便於閱讀的副本，不是簽章或 canonical 證據；完整原始回應 JSON 下載仍逐字保留原件與分析，兩者各有按鈕。CSV 不受畫面顯示精度影響，只有明確按下載才在本機建立檔案，不請求 API、不重算、不寫資料庫。更換或清空選擇、帳戶版本變更及衝突沿用原本結果失效規則。

## 驗證

Python 測試以手算 +10%、−10% 串接成 −1%，檢查可加的 +10、−11 淨值變動，以及首月現金邊界、真正完整月、部分月、跨年十二格、期間外 null、零報酬、無效值、日期缺漏、溢位與下溢；tmp_path server-generated 原回條測試核對、252 日、快照、過期來源、無重算、指紋／範圍／版本／損壞與完整 JSON 大小限制。UI 測試涵蓋文字加顏色、部分月已知值、期間外缺值、時間順序、草稿、取消、連點、衝突及 exact raw JSON 下載。

CSV 測試額外覆蓋跨年 13 個觀察月與 24 個年度格的區別、部分月涵蓋與真正零值、來源 metadata、缺漏／非有限拒絕、文字公式與引號／換行安全、明確下載及原始 JSON 逐字保留。
