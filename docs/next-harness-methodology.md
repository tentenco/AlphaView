# 下一輪方法與驗收工作單

本文件是下一輪可選的開發 brief，尚未實作或自動授權執行。現有多標的調整價比較、目前持倉集中度／相關性、單股策略回測及同股買入持有基準已完成；不應重做，也不應將它們改名為歷史投資組合績效。實際資料限制見[來源評估](data-provider-evaluation.md)，現有比較口徑見[標的比較](candidate-comparison.md)。以下數字全部是假設測試資料，並非真實行情或投資建議。

## 1. 先建立交易與現金流帳本

交付順序：事件匯入預覽與對帳 → 可重播帳本 → 公司行動 → 歷史估值覆蓋 → 報酬方法。現有股數／平均成本只能成為明確日期的期初餘額；不能倒推出購買日、歷史現金流或成交紀錄。

第一版建議限定單一美元帳戶、僅做多、允許小數股；不含融資、放空、多幣別與稅務申報。這能縮小驗收範圍，但不代表其他帳戶可無損匯入。每筆事件至少記錄穩定 ID、標的身份、類型、有效時間、記錄時間、股數、價格、費用、幣別、來源與修訂關係。重複匯入不得重複入帳；修正用反向／替代事件保留歷程，禁止靜默覆寫。

開始前需要決定並寫入方法版本：

- **成本基礎**：FIFO、移動平均或指定批次；費用分攤與小數精度。本 brief 的驗收樣例採移動平均，買入費用併入成本、賣出費用扣除所得；這是產品計算約定，不是稅務結論。
- **成交與現金時間**：分開記錄成交、交割、公司行動生效與現金入帳時間。若首版採成交日經濟帳本，交割中金額須獨立列示，不能冒充可提領現金。真實成交以匯入紀錄為準；日線策略模擬仍維持前日訊號、次日開盤成交。
- **外部流量**：入金／出金與股息、利息、交易費用分開；帳戶間移轉如何處理由報表範圍決定。外部入金不算投資獲利。
- **公司行動**：拆股有效日、除息權利與應收股息、付款日、預扣款及再投資都需獨立事件；不從價格跳空猜測事件。保留原始未調整價格與已驗證事件，避免同時使用含股息調整價和入帳股息重複計算。

每組都要驗證事件順序、重載重播、修訂撤回、重複匯入、現金與股數守恆。取消或失敗不能發布半份帳本。未支援事件要明列阻塞原因；缺價時保留估值缺口，不以最後價格製造完整曲線。

報酬功能需要另選口徑：逐外部流量分段要求可靠的流量前／後估值；只有日末估值時不能假稱有精確日內分段。若另做資金加權報酬，需明定日曆與現金流正負號、求解區間、無解／多解處理，不能把任意一個求解值當成唯一答案。帳本驗收完成前，不上線 TWR／XIRR 等標籤。

## 2. 外部市場基準：獨立驗證後掛接

保留現有同股基準。SPY 等外部基準使用獨立身份、資料集、來源時間、原始內容雜湊、調整口徑與驗證結果；不共用目標股票名稱，不將未審核 repair 結果直接寫入正式行情。

驗收需覆蓋：與策略相同的實際開始開盤、最後收盤、完整交易日與暖機之後的期間；明示基準費用是否為零。以假設基準開盤 50、末日收盤 55、零費用、初始 1,000 為例，應持有 20 單位、終值 1,100、報酬 10%。若改成「共同收盤起點」比較，應使用另一個已標示的方法，不能沿用同一名稱混算。

缺任何必要基準價格／身份不明／公司行動調整未通過時，外部基準單獨不可用；原策略結果與同股基準仍可檢查。至少以獨立來源或可驗證公司行動資料交叉核對抽樣，但不把兩來源相同當成全歷史正確的證明。換來源先建立新版本與差異報告，不拼接成來源不明的連續曲線。

## 3. 指標版本與歷史股票池

指標公式、暖機、RSI 種子、缺值處理、成交時點、費用口徑或身份規則有實質變更時，遞增受影響的計算版本並保留舊結果；不能只改文案後覆蓋既有研究。驗收應包含手算邊界、拆股等價表示、未來資料不改歷史前綴，以及舊版本不可冒充本次結果。只改 UI 排版不應使數值方法版本變動。

歷史股票池至少記錄成分有效起迄、當時可得時間、發布時間、來源版本與標的身份轉換；加入退市與更名資料時保留原身份鏈。假設 X 在 D3 才公告加入、D4 生效，D2 的掃描不得使用這項未公開成分資訊。另以已退市 Y 的 fixture 驗證它仍出現在退市前的合法研究範圍。

若只有今日候選池回看歷史，繼續明示存活者與選樣偏差；不能宣稱是歷史全美股選股回測。財務資料也要保留公告可得時間，修訂值不得滲入修訂公布以前。參數挑選與成效評估分開保存期間；樣本外檢查只能增加證據，不能保證未來獲利。
