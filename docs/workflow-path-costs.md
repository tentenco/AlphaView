# 保存工作流：相同決策的成本情境

`alphaview-workflow-path-costs-v1` 比較同一保存設定歷史路徑在少量、明確費用與滑價假設下的帳務差異。原路徑仍是 `alphaview-workflow-path-validation-v1`：固定候選與股票池、252 個交易日、每 21 日以前日收盤決策、次日未調整開盤成交、初始現金 100,000。

這不是什麼：不是成本最佳化、訓練、參數搜尋、樣本外驗證、成交保證或交易指示；不評選最佳情境、不產生通過結論，也不改變提案、執行層與帳戶閘。固定 bps 滑價不是流動性、成交量或市場衝擊模型。原路徑的事後選股、倖存者與資料修訂限制仍存在。

## 一次決策，完整保留原基準

唯讀端點 `POST /api/portfolio-agent/runs/{id}/path-costs` 要求保存工作流的 `expected_proposal_fingerprint`、`expected_input_revision`、`expected_as_of`。在同一 `@store.snapshot_read` 快照內，僅呼叫一次原路徑引擎，保留完整 `baseline` 與原 `evidence_fingerprint`。每個情境重用該次 prefix-only 決策、日期及目標百分比，不重新呼叫訊號或配置器。

原基準固定為單邊費用 10 bps、滑價 0。若要求的情境包含這組假設，直接重用原基準數值；不靠另一套公式重新計算再聲稱一致。使用者未列入原基準時，回應仍保留完整原基準作為差額分母。

`fee_bps` 與 `slippage_bps` 各接受 1–3 個不重複、有限的 0–100 bps 數值，笛卡兒積最多 9 組。預設費用為 `[0, 10, 25]`、滑價為 `[0, 5, 10]`。1 bps = 0.01%。零成本是明確假設，缺值不當作零；重複、布林、字串、非有限數及超界值回 422。

## 成本與目標權重的帳務口徑

每次再配置，令：

- `E` 為交易前，持股以未調整開盤標記的資產加現金。
- `w_i` 為原決策目標百分比；沒有目標的原持股 `w_i = 0`。
- `H_i` 為原持股數乘未調整開盤；`f`、`s` 為費用與滑價的小數比率。
- `N` 為扣完本次明列成本後、仍以未調整開盤標記的資產。

解下式（80 次有界二分）：

```text
delta_i(N) = w_i * N - H_i
execution_i = abs(delta_i) * (1 + s)  when buying
execution_i = abs(delta_i) * (1 - s)  when selling
fee_i = execution_i * f
slippage_i = abs(delta_i) * s
N + sum(fee_i + slippage_i) = E
```

買入成交價為 `raw_open * (1 + s)`，賣出為 `raw_open * (1 - s)`；股數變化為 `abs(delta_i) / raw_open`，費用按滑價後成交金額收取。新持股的未調整開盤市值為 `w_i * N`，剩餘權重保留現金。因成本而變少的是本金與股數，原目標百分比不重新分配。

現金以實際買入支出、賣出收入與費用守恆。明列成本包含費用與滑價，不重複扣除。持股每日以未調整收盤估值，現金報酬為零，期末不強制清算；原決策沒有符合候選時保留原持股。

`final_value`、`return_pp`、`max_drawdown_pp` 與 `explicit_cost` 差額皆為「情境減原基準」。回撤為非正數，正的回撤差表示較不負，不額外轉成評分。期末資產差包括股數與後續複利差異，不必等於費用加滑價的差額。

## 缺口、來源與下載

原基準不可用時，所有情境都不可用，指向原始原因；持有期間調整因子變動也沿用原基準的不可用規則，不捏造股息、拆股或其他權益。固定目標讓每個可用情境的持有標的集合與基準相同。單一情境出現非有限或帳務錯誤時，該情境全部績效、成本、曲線與成交留空，其他情境仍可用。

回應提供原基準、歷史、共同決策、成本假設與整份證據指紋，以及情境所需／可用／不可用覆蓋數。再次載入本機歷史必須和原基準指紋相符；一致快照阻止並行寫入混合新舊行情。交易日於計算期間切換則回 409。無資料庫寫入、供應商、模型或券商呼叫。

UI 顯示全部要求情境，沒有依績效排序；可選任一情境查看資產路徑與逐筆模擬成交，包括原開盤、含滑價成交價、股數、成交金額、費用與滑價。資產與報酬顯示 2 位小數，成本及百分點差異顯示 4 位；股數顯示 6 位。下載保留 API 接受的原始 JSON 字串，不經 JavaScript 數字再序列化，以保留原數值字面與證據指紋。

計算後先核對保存來源，之後每 30 秒及恢復可見時核對；來源不再當期或核對失敗時移除結果與下載。輸入假設變更會移除舊結果、取消待處理請求，保留使用者草稿。重新整理不自動計算。
