# AlphaView local setup

## Web workspace

```sh
uv sync --locked --extra web --extra dev
npm ci --prefix web
npm run build --prefix web
uv run --extra web python -m alphaview.panel serve
```

Open http://127.0.0.1:8876. Full usage and research methodology are in [WEB_PANEL.md](WEB_PANEL.md).
`PANEL_DB_PATH` can point to an isolated workspace. The default is `data/panel.db` in the checkout.

The repository contains no personal portfolio seed. The optional `seed` command adds seven zero-share starter watchlist symbols and preserves existing positions.

## Validation

```sh
uv run --extra web --extra dev pytest -q
npm run build --prefix web
uv build
```

## Optional A-share CLI

The independent command-line workflow uses `main.py` and its own database.
It is not required for the US-stock dashboard.

```sh
cp .env.example .env
# Configure the optional workflow locally.
uv run python main.py --backfill
uv run python main.py
```

The default A-share database is `data/alphaview_ashares.db`. Existing local installations that set `DB_PATH` retain their chosen path. No database is renamed or deleted during the brand migration.

An empty Feishu webhook skips delivery. Running the optional daily CLI with a configured webhook sends notifications. The web panel does not send Feishu notifications or place trades.

Do not run separate writers on the same database concurrently. Backfill duration depends on the provider and connection; interrupted downloads can be resumed. No external schedule is installed by setup.

## Local-only files

Keep `.env`, `data/`, logs, and `artifacts/` out of Git. Local harness review reports and database backups belong in `artifacts/`. Build archives in `dist/` are generated by `uv build`.
